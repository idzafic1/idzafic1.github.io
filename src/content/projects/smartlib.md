## Overview

A collaborative C#-based library management system featuring a real-time book catalog, user account roles, and automated reservation tracking.

## My role

Team member in an 8-person engineering team. Contributing to backend service modules and database integration.

## Approach

The system connects to a cloud-hosted TiDB relational database instance and utilizes modern C# application architecture deployed on Render cloud infrastructure.

## Results

Core data schemas, catalog search, and reservation workflows are implemented and actively maintained in staging.
