## Overview

A C#-based two-sided service marketplace connecting local service providers with clients, featuring role-based access control and listing management.

> **Status Notice**: Live site temporarily offline (hosting quota). Source code available.

## My role

Team member in a team of 4. Contributed to core C# application workflows, backend data modeling, and testing.

## Approach

The platform supports distinct user roles (clients and service providers), service listing creation, category filtering, Google SMTP integration for automated account verification, and secure profile management.

## Results

Delivered a functional marketplace web application meeting team requirements. Complete source code is publicly accessible in the repository.

## What I learned

Collaborative application development requires continuous alignment on shared interface contracts, Git workflows, and structured task division across team members.
